# Інструкції для Claude Code

- Git ведемо за [docs/GIT.md](docs/GIT.md): робота в гілках `<тип>/<назва>` від `main`, Conventional Commits англійською зі scope за секцією сайту, один коміт = одна логічна зміна, у `main` лише через PR.
- Після кожної завершеної задачі оновлюй [docs/PLAN.md](docs/PLAN.md): галочки і рядок у «Журнал прогресу» — у тому ж коміті/PR.
- Верстка — за [docs/DESIGN.md](docs/DESIGN.md) і `docs/design/`; стек — за [docs/STACK.md](docs/STACK.md).
- Документація й тексти — українською.
